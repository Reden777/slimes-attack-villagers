# slimes-attack-villagers
A little jarmod (so not forge/legacy fabric, at least for now) that does what it says on the tin. Slimes will target villagers within 16 blocks.

To install, put the class inside the minecraft 1.2.5 jar and delete META-INF, as was traditional in ancient times.

You can also install it with the help of [https://github.com/MCPHackers/RetroMCP-Java](RetroMCP).

Errata: Currently there's no attack sound.

Slimes may still target dying villagers (untested).
